# Canva Sans integration

Place the following files in this folder to activate Canva Sans headings globally:

- CanvaSans-Regular.woff2
- CanvaSans-SemiBold.woff2
- CanvaSans-Bold.woff2

The app already includes `@font-face` declarations in `app/globals.css` and will fallback to Inter if these files are missing.
